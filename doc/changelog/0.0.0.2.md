# tron 0.0.0.2 (unreleased)

Changes since 0.0.0.1.

- Added: MCP engines (doc/mcp-engines.md). An extension registers an engine as `[McpEngine_<id>]` in its own
  tron.ini; several engines are active at once, each engine's tools under `<id>__<tool>`, checked and audited by
  tron like its own programs. Two interfaces: the neutral contract `tronMcpEngine`, and `tronMcpBridgeApi` for
  classes of the bridge API, which are wrapped without an adapter (`tronMcpBridgeEngine`).
- Added: `tronMcpEngineHub`, the engines as a host in the same request sees them (`tron__<tool>` for tron's own
  programs), and `tronMcpTronEngine`, tron itself as an engine.
- Added: The interface scan over the autoload array and `bin/php/tron-engines.php` (engines, scan, a user's tools).
