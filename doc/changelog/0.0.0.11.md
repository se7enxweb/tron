# tron 0.0.0.11 (unreleased)

Changes since 0.0.0.10.

- Updated: Every file carries the copyright notice in the owner's wording (tronVersion::NOTICE, quoted at the end of
  this page): the PHP docblocks, ezinfo.php, extension.xml, the README and documentation pages, the templates, the
  stylesheet, the settings files, the translation catalogues, the skill pack READMEs and the generated schema files.
  Where a line also states the license, the license follows as its own sentence.
- Added: tests/unit/CopyrightNoticeTest.php fails on a file without the notice, on a notice of the holders in
  another wording and on release fields that differ; tronVersion::NOTICE holds the wording.
- Updated: Setup > tron > Diff is declared with the other views of the module, the agent rules styles appear once in
  the stylesheet, and "and %n more" has its English and German translation.
- Updated: tron-inventory.php, tron-rules.php and tron-skills.php are executable like the other command line scripts.
