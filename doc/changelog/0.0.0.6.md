# tron 0.0.0.6 (unreleased)

Changes since 0.0.0.5.

- Added: The agent rules layer (doc/agent-rules.md). Every agent receives the project's rules with its session: the
  site's own AGENTS.md and MASTER.md, the Exponential rules that supersede it where the two conflict. They are
  appended to the `initialize` instructions and served as the resources `tron://rules/agents`, `tron://rules/master`,
  `tron://rules/combined` and `tron://rules/status`, the prompts `tron_project_rules` and `tron_rules_wizard`, and the
  tool `tron_rules`. Each answer names its `source` (default, override, off, none); `tron_status` has a `rules` field.
- Added: MASTER.md shipped in `doc/MASTER.md`, generated from the project's working rules by a sanitizer that keeps an
  allow list of sections, drops private material and replaces secrets, host names, addresses and paths with
  placeholders. `bin/php/tron-rules.php sanitize` refuses to write a file in which `check` finds anything.
- Added: A site override of MASTER.md and the site's AGENTS.md in `<VarDir>/storage/claude/prompt/`; the override
  replaces the shipped file while it exists.
- Added: Seven switches for MASTER.md in a documented precedence: the file marker `MASTER.disabled`, the environment
  variable `TRON_MASTER_RULES`, the admin toggle, tron.ini `[PromptRules] Master` (per siteaccess too), the default,
  then a user's preference and a session's flag (`initialize` `_meta` `tron/masterRules`, `tron_rules`, the prompt
  argument), which can only switch it off.
- Added: Setup > tron > Agent rules: sources and switches, the AGENTS.md editor with upload, a questionnaire that
  writes a starter AGENTS.md without any model, a draft through Exponential Intelligence where expai is active, the
  MASTER.md override, and the combined text. Saving, uploading, removing, the admin toggle and the marker ask
  "Verify it's you" and are audited.
- Added: `bin/php/tron-rules.php` (sanitize, check, generate, status, combined) and tron.ini `[PromptRules]`.
