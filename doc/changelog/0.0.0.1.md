# tron 0.0.0.1

First version (wave 1).

- Added: MCP server core speaking 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05: initialize, ping, tools,
  resources, resource templates, prompts, pagination, JSON-RPC errors, batches where the version has them.
- Added: stdio transport (`bin/php/tron.php serve`) and stateless streamable HTTP transport (module view `tron/mcp`,
  off until `[HTTPSettings] Enabled=true`).
- Added: per-user tokens (hashed, expiring, revocable, scoped to programs) with `token:create`, `token:list`,
  `token:revoke`.
- Added: permission checks through the installation's roles and policies; module `tron` with the functions use,
  admin, centre_read, centre_write, centre_decide, katalyst_read, katalyst_detail.
- Added: audit log (table `tron_audit` and/or a JSON-lines file); write tools audited before they run and refused
  when the audit cannot be written; `audit:tail`.
- Added: programs found by convention (`extension/<ext>/tron/program.json`), loaded in isolation with staged
  registration; status per program.
- Added: program `tron` (tron_whoami, tron_status, tron://status, tron://programs).
- Added: program `centre`: 12 ticket, card and decision tools with resources and prompts on tron's own tables, or
  the 17 tools of centre's API contract where expcentre is in the installation.
- Added: program `katalyst`: read-only services, plans and orders with a column allowlist and domain masking.
- Added: schema for PostgreSQL, MySQL/MariaDB and SQLite from one declaration; `tron.php install`.
- Added: test suite (unit, per-role permissions, MCP conformance over real stdio and HTTP), PHP matrix 7.4 to 8.5,
  read-only kernel probe and stdio smoke client.
- Added: administration views under Setup > tron (dashboard, tokens, programs and tools with switches and the roles
  that grant each policy, audit with filters and a live tail, settings through the INI editor); the policies
  `tron/tokens` and `tron/audit`; table `tron_switch`; reauth group `tron`; translations eng-GB and ger-DE.
- Added: the proving run, HTTP smoke client and request shield rules (`doc/request-shield/tron.rules`).
- Added: preview docs: getting started, guides for agent operators, site administrators and program authors, a
  cookbook of eight examples run by the test suite, theory and proofs (every claim tied to a test), troubleshooting,
  FAQ.
- Updated: ten defects found on the development installation fixed (doc/testing.md).
- Added: rotating (and renewing) tokens in Setup > tron > Tokens, `tronTokenService::rotate()`; user filter forms
  on Tokens and Audit; the administrators' actions (token made, rotated, revoked; switch changed) in the audit log
  as transport `admin`; counts and limited roles on Programs and tools.
- Updated: the administration views' data split into one class per view on a request context (`classes/admin/`,
  refactor item R7), with unit tests on SQLite.
