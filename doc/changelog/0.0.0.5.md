# tron 0.0.0.5 (unreleased)

Changes since 0.0.0.4.

- Added: The activity journal (doc/activity-journal.md). Every MCP session and background job becomes a story that
  can be read later: the session (user, token, client, transport, node, start and end), the intent and notes the
  agent gives, each step with its arguments, result summary, duration, outcome and code, the objects it touched
  (nodes, objects, layouts, INI keys, files ...), and the diff or plan reference of every write. Fed by the audit
  entries, redacted like them, and chained per session by a SHA-256 hash so a changed, removed or inserted step is
  detected. Answers that contain JSON objects are journaled like plain arrays.
- Added: The tools `tron_journal_note`, `tron_journal_list`, `tron_journal_show` (narrative, timeline, Markdown,
  JSON) and `tron_journal_search` (by user, day, tool, outcome, object, text).
- Added: Background jobs write progress, checkpoints and their result into the journal (`tronJournalJob`), and
  `bin/php/tron-journal.php job:run` journals any command.
- Added: Setup > tron > Activity: sessions with filters, a session's story, timeline and diffs, an object's history,
  exports as text, Markdown and JSON. English and German.
- Added: `bin/php/tron-journal.php` (list, show, search, verify, rotate, job:run) and tron.ini `[JournalSettings]`
  (retention with an archive, idle window, diff storage and limits).
- Added: Three tables, `tron_journal_session`, `tron_journal_step`, `tron_journal_object` (`tron.php install`).
