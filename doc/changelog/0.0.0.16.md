# Exponential Tron 0.0.0.16

Changes since 0.0.0.15.

- Updated: the classes of the official MCP SDK layer (`tronSdkHandler`, `tronSdkLogger`, `tronSdkProtocol`) parse on
  PHP 7.4 and 8.0 again. 0.0.0.15 wrote them with constructor promotion, readonly properties, named arguments and a
  union return type; they run only on PHP 8.2 with `mcp/sdk`, but an installation's boot check and autoload
  generator parse every class on whatever PHP runs them, so installations on PHP 7.4 and 8.0 failed there. The
  handler now declares the narrower return type `Response` and throws tron's protocol errors; the new event
  dispatcher `tronSdkErrors` gives the client tron's own code, message and data for them, as before.
- Added: a GitHub workflow lints every PHP file of Exponential Tron on PHP 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 and 8.5 and
  runs the suite on PHP 7.4 (the legacy protocol layer) and 8.5 (the official MCP SDK). `tests/matrix.php` lints the
  SDK layer's files on every PHP again; it had left them out below 8.2, which hid the regression.
- Updated: the README, the documentation, the skill pack READMEs, the package description and the extension name call
  the product Exponential Tron. The package (`se7enxweb/tron`), the extension (`tron`), the commands, settings and
  identifiers keep their names.

## Upgrade note

Installations on PHP 7.4 and 8.0 that took 0.0.0.15 need this release. Nothing else changes: no schema change, no
setting.
