# tron 0.0.0.8 (unreleased)

Changes since 0.0.0.7.

- Added: Dry runs (doc/dry-run.md). Every write tool runs as a dry run that changes nothing and returns the exact
  change (rows with from/to, or attributes and versions, and the effects outside the tables) and a plan id;
  `tron_apply` makes exactly that change or refuses (another user or token, other arguments, expired, used, or the
  target changed since). Two kinds: a transaction rolled back with the tables diffed (the centre tools) and a computed
  plan (content, centre's API). Also through `_meta` (`tron/dryRun`, `tron/planId`). New table `tron_plan` (hashes
  only); `tron.php install` adds it.
- Added: The program content with `content_node_update`: a new published version of a node with text lines, text
  blocks, integers, floats and checkboxes changed, as the session's user, gated by content/edit and the kernel's
  object check.
- Added: The policy simulator `tron_policy_check` (doc/policy-simulator.md): could a user call a tool, read a
  resource, get a prompt (or everything of a program), with a target and a simulated token scope; answers from the
  real roles and policies with the deciding gate (use, scope, policy, target), the matching roles, policies and
  limitations and the reason. Checking someone else needs tron/admin.
- Added: Contract testing (doc/contract-testing.md): every tool declares an output schema (listed in tools/list from
  2025-06-18 on), every write tool a dry run; `tests/fuzz.php` fuzzes every tool with valid, boundary, malformed,
  injection, unicode, huge and canary inputs on two identical worlds, on SQLite and PostgreSQL, and in the PHP matrix
  (`TRON_MATRIX_FUZZ`).
- Added: Secrets-blind answers (doc/redaction.md): every answer passes the redactor (secrets, tokens, keys, DSNs,
  e-mail addresses, phone numbers); the audit detail records the kinds and counts masked. `[RedactionSettings]`.
- Updated: tronDb nests transactions as savepoints (PDO and the kernel's eZDB).
- Updated: The schema validator refuses strings that are not UTF-8; ids and positions of the centre, content and
  Katalyst tools are bounded to 2147483647 (both found by the fuzzer on PostgreSQL, where they were internal errors).
- Updated: tronServer::invoke() runs a call, a dry run or an apply for the server and for tron_plan/tron_apply.
