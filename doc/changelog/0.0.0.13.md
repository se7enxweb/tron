# tron 0.0.0.13

Changes since 0.0.0.12.

- Updated: A private name of `[PromptRules] PrivateNames[]` ends where a word ends, as before 0.0.0.12. In 0.0.0.12
  a hyphen next to the name hid it, so a line naming `<name>-editor` stayed in a generated MASTER.md and `leaks()`
  did not report it. Use 0.0.0.13 instead of 0.0.0.12 wherever private names are set.
