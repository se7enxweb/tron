# tron 0.0.0.12

Changes since 0.0.0.11. The first public release: the repository is
[github.com/se7enxweb/tron](https://github.com/se7enxweb/tron) and the package `se7enxweb/tron` on Packagist.

- Updated: The MASTER.md sanitizer reads an installation's private names, internal domains and private network from
  that installation's settings instead of its own code: `[PromptRules] PrivateNames[]` and `PrivateDomains[]`, and
  `[WebSettings] MeshNetworks[]`, set in `settings/override` and never shipped. The command line reads
  `settings/override/tron.ini.append.php` from the installation root; with the kernel loaded the INI is used.
  `leaks()` reports them as "private name", "internal host" and "private network address".
- Updated: The names the system catalog and the system tools leave out (an installation's other MCP servers, private
  client projects) come from `[SystemAdapterSettings] PrivateNames[]` in `settings/override` instead of a pattern in
  tron: a whole word, or the beginning of a word with a trailing `*`. tron ships none. The test fixture's private
  extension is a neutral placeholder.
- Updated: The SSRF guard's "mesh" kind comes from `[WebSettings] MeshNetworks[]` (IPv4 CIDRs); tron ships it empty,
  and such addresses are then refused as "private". The browser runner receives the same list with each job.
- Updated: The hosting page describes a load balancer in front in general terms, with example.org names; the
  testing, journal and contributing pages use neutral names and point to the public repository.
- Updated: The README carries the Packagist badge and installs from the public repository.

## Upgrading

An installation whose AGENTS.md names private servers, domains or a private network that must stay out of a
generated MASTER.md sets them in `settings/override/tron.ini.append.php`:

```ini
[PromptRules]
PrivateNames[]
PrivateNames[]=<private server name>
PrivateDomains[]
PrivateDomains[]=<internal domain>

[WebSettings]
MeshNetworks[]
MeshNetworks[]=<IPv4 CIDR>

[SystemAdapterSettings]
PrivateNames[]
PrivateNames[]=<private extension prefix>*
PrivateNames[]=<private project word>
```
